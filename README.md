# MedCite

The first front-end foundation for MedCite, a simple NLM-style citation tool for English medical journal articles.

## Run locally

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

The current page is a front-end preview. DOI lookup, citation formatting, copying, and editing are not connected yet.
